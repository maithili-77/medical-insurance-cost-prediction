# Medical Insurance Cost Prediction

## Project Description

This project predicts annual medical insurance costs using machine learning.

## Dataset

Medical Insurance Dataset

## Target Variable

annual_medical_cost

## Machine Learning Models

1. Multiple Linear Regression
2. Ridge Regression
3. Lasso Regression
4. Decision Tree Regression
5. Random Forest Regression

## Evaluation Metrics

- MAE
- RMSE
- R2 Score

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Gradio

## Prediction Interface

A Gradio interface is created for predicting annual medical costs.
